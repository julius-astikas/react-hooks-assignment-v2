# React Oppgave 2 – useState() and useEffect()

React assignment created to practice React Hooks, especially `useState()` and `useEffect()`.

## Features

- CookieClicker with a point counter
- Interactive cookie click feedback and confetti
- Cat facts fetched from the Cat Facts API
- Loading and error states
- User list initialized from mock data
- Add new users with form validation
- Responsive layout

## Technologies

- React
- Vite
- JavaScript
- CSS
